- **编排：** 自研多节点 LLM 有向图与节点级状态机，支持人工、交接、全自动三种推进模式；任务可暂停、接管、超时恢复，全程审计留痕。跨服务长事务由 Temporal 承载，进程重启后从上一成功步骤续跑
- **框架：** 熟悉 LangGraph、LangChain、LlamaIndex、OpenAI Agents SDK、Dify。原型与轻量工作流用 Dify / LangChain 快速验证；生产主链路需要节点级人工审批和跨进程续跑，因此采用自研状态机与 Temporal
- **工具与上下文：** 内部工作流封装为 HTTP / MCP 工具目录供 Agent 调用；结构化输出做 JSON Schema 与业务规则双重校验，校验失败时把错误结构回写给模型重试；长上下文按分段边界装配与压缩；多模型统一路由，失败自动降级到备用模型
- **实时交互：** SSE 流式输出与 WebSocket 双向通道，前端实时展示 Agent 每一步的执行过程，人可以中途打断、修改后交回模型继续执行

### 2. 检索与知识工程

- **图像资产检索：** 图像先抽取为结构化文字描述 → 查询归一化 → 标量预过滤 → pgvector（HNSW）+ bge-m3 向量召回 → 重排模型精排；用自建人工标注评测集决定方案选型
- **记忆与文档：** 已完成的产物抽取成实体 / 场景 / 情节记忆并增量写回；文档按行号规范切分入库，检索结果可回指原文位置

### 3. 评测、可观测与生产可靠性

- **效果评测：** 检索侧用人工标注 golden 集逐题归因；生成侧用 LLM-as-a-Judge 分维度打分，并定期与人工评审抽样比对一致性；换模型或改提示词先走灰度 A/B，指标不退化再全量
- **可观测：** Langfuse / LangSmith 追踪 LLM 调用链，按节点记录 token、成本、延迟与提示词版本；服务侧接入 OpenTelemetry；失败按模型、检索、工具、工作流四类归因，按根因修复
- **可靠性：** 任务投递用 outbox 模式，Worker 用 `SELECT ... FOR UPDATE SKIP LOCKED` 竞争取任务，配合幂等写入与分布式锁；内容合规与画面质检设在不可逆节点前，回归用例纳入发版门禁
